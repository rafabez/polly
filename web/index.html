POLLY

Cross-Platform Terminal AI Assistant

Assistente de IA Cross-Platform para Terminal

Polly is a free, open-source cross-platform terminal assistant that brings AI-powered help directly to your command line.

Polly é um assistente de terminal cross-platform gratuito e open-source que traz ajuda com IA diretamente para sua linha de comando.

Ask questions, generate commands, debug code and learn Linux without leaving your terminal.

Faça perguntas, gere comandos, debugge código e aprenda Linux sem sair do terminal.

Powered by multiple AI models through Pollinations.ai, Polly makes system administration and development faster and more accessible.

Alimentado por múltiplos modelos de IA via Pollinations.ai, Polly torna administração de sistemas e desenvolvimento mais rápidos e acessíveis.

polly@terminal:~$ 
$ polly "What is recursion?"

Recursion is a programming technique where a function 
calls itself to solve a problem by breaking it down 
into smaller, similar subproblems...

$ polly -c "find large files"

find . -type f -size +100M

$ polly -i
Interactive mode - Type 'exit' to quit
You: _
$ polly "O que é recursão?"

Recursão é uma técnica de programação onde uma função 
chama a si mesma para resolver um problema dividindo-o 
em subproblemas menores e similares...

>> INSTALLATION

Quick Install (pipx) Instalação Rápida (pipx) 
# Install pipx
sudo apt install pipx

# Install Polly
pipx install git+https://github.com/rafabez/polly.git

# Test it
polly --version
Alternative (venv) 
git clone https://github.com/rafabez/polly.git
cd polly
python3 -m venv venv
source venv/bin/activate
pip install .
